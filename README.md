## 💻 Stack Tecnológico

- **Framework:** [Astro v4](https://astro.build/) (Static Site Generation - SSG)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Despliegue Continuo:** GitHub Actions (`.github/workflows/deploy.yml`) hacia GitHub Pages con dominio propio `lapontech.com`.
- **Rendimiento:** 95-100 en Google PageSpeed, cero JavaScript innecesario en cliente.

---

## 🛠️ Comandos de Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo local
npm run dev

# Compilar para producción (genera directorio ./dist/)
npm run build

# Previsualizar la compilación de producción localmente
npm run preview
```
